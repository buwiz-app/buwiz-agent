# AGENTS.md

Buwiz Agent: the types Buwiz mini apps, the Bot and the broker share, in Rust (`crates/agent`, the crate `buwiz-agent`)
and TypeScript (`packages/agent`, the package `@buwiz/agent`). The README says what each part is.

## Invariants

1. **Rust is the source.** Types change in `crates/agent`. `packages/agent/src/generated.ts` and
   `packages/agent/schema/buwiz-agent.schema.json` are generated by `buwiz-agent-gen` and never edited by hand.
2. **Two halves, one behavior.** The parsers and `authorize_press` exist in both languages. A change to one half is
   made to the other in the same commit, with a case in `vectors/`, which both halves run.
3. **Fails closed.** Unknown, missing or malformed means refused: unknown fields, unknown ops, unknown effects,
   unknown callers. Nothing has a permissive default.
4. **Each press needs its own approval (D1).** An AI press on a `write` or `file` action needs an `Approval` bound
   to that target, action and one-time id. A routine is always refused one. `read` and `draft` need no approval.
5. **Every message names its app (D2).** `target` is the app, on every message. The node inside the app is `node`.
6. **Integers only.** No floats in any type. Anything wider than 2^53 - 1 is not a JSON number: use `SafeU64`, or a
   string as `Fingerprint` does.
7. **Handles, not personal data.** Actors are handles and context is a `ctx://` ref. No type needs a real name, email
   or TIN, and errors never repeat the value they refused. `Envelope`'s `Debug` hides `auth`.
8. **Fakes only.** No real TIN, email, name, ticket value or secret in code, tests or vectors. No third-party
   character names, recipes or pictures.
9. **Standalone.** Nothing depends on the Bot, nsh, gpui or gpui-agent crates. Shapes are copied, not imported.

## Gates

`tools/check-all.sh` passes before every commit: `cargo fmt --check`, `cargo clippy --all-targets -D warnings`,
`cargo test`, the generated-files check, then `bun run check` (oxlint, oxfmt, tsc) and `bun test`.
